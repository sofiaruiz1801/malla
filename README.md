### 📌 Sobre el Proyecto

**Malla** es una solución diseñada para simplificar el seguimiento del plan de estudios de estudiantes universitarios de la UNC. Permite llevar un registro claro de materias aprobadas, notas, cálculo automatizado de promedios (con y sin aplazos), cómputo de créditos e identificación de correlatividades habilitadas para cursar y rendir.

El proyecto se desarrolla de forma iterativa bajo metodología **Scrum**, priorizando buenas prácticas de arquitectura de software, modelado de bases de datos relacionales y diseño de APIs RESTful.

### 🚀 Roadmap de Desarrollo

- [x] **Sprint 1:** Análisis de requerimientos, diseño de arquitectura y especificación de dominio.
- [ ] **Sprint 2:** Modelado de base de datos, relaciones de correlatividad y seeders con mallas 2025.
- [ ] **Sprint 3:** Desarrollo de API RESTful, autenticación y lógica de negocio core.
- [ ] **Sprint 4:** Desarrollo de interfaz web (Frontend MVP) e integración continua.

### 🛠️ Tech Stack

- **Backend:** Node.js / TypeScript / NestJS
- **ORM:** TypeORM

- **Frontend:** React / Next.js *(A confirmar)*

## 🇬🇧 English

> Web platform for academic tracking, GPA calculation, and prerequisite visualization for UNC students.

![Project Status](https://img.shields.io/badge/Status-In_Development-yellow)
![License](https://img.shields.io/badge/License-MIT-blue)

### 📌 About the Project

**Malla** is a web application designed to streamline degree progress tracking for university students at the National University of Córdoba (UNC). It provides a clear record of completed courses, grades, automated GPA calculation (with and without failed attempts), credit count, and identification of unlocked prerequisites for enrolling and taking final exams.

The project is developed iteratively following **Scrum** methodology, focusing on software architecture best practices, relational database design, and RESTful API architecture.

### 🚀 Development Roadmap

- [x] **Sprint 1:** Requirements analysis, architecture design, and domain specification.
- [ ] **Sprint 2:** Database modeling, prerequisite relationships, and seeders for 2025 curricula.
- [ ] **Sprint 3:** RESTful API development, authentication, and core business logic.
- [ ] **Sprint 4:** Web interface development (MVP Frontend) and continuous integration.

### 🛠️ Tech Stack

- **Backend:** Node.js / TypeScript / NestJS
- **ORM:** TypeORM
- **Database:** PostgreSQL
- **Frontend:** React / Next.js *(TBD)*
- **Documentation & Tools:** Swagger, Docker, Jira

### 📂 Domain Documentation
