## 📌 Sobre el Proyecto

**Malla** es una solución diseñada para simplificar el seguimiento del plan de estudios de estudiantes universitarios de la Universidad Nacional de Córdoba (UNC). Permite llevar un registro claro de materias aprobadas, notas, cálculo automatizado de promedios (con y sin aplazos), cómputo de créditos e identificación de correlatividades habilitadas para cursar y rendir.

El proyecto se desarrolla de forma iterativa bajo metodología **Scrum**, priorizando buenas prácticas de arquitectura de software, modelado de bases de datos relacionales y diseño de APIs RESTful.

## 🛠️ Tech Stack

- **Backend:** Node.js / TypeScript / NestJS
- **ORM:** TypeORM
- **Base de Datos:** PostgreSQL
- **Frontend:** React / Next.js *(A confirmar)*
- **Documentación & Tools:** Swagger, Docker, Jira
